# Castellan Estates

*Residences beyond time.* A cinematic luxury real-estate experience where
scrolling feels like walking through the estate itself.

![Hero](public/images/hero.webp)

## The experience

- **Opening title card** — the monogram draws itself, a counter climbs, and
  the veil parts like theatre curtains.
- **Minimal hero** — one headline, one line, a scroll cue. No navigation
  until the journey begins.
- **The cinematic walkthrough** — the centrepiece. A pinned, scroll-scrubbed
  `<canvas>` sequence walks sixteen chapters through the estate: exterior →
  approach → threshold → lobby → gallery → living hall → kitchen → dining →
  master suite → dressing room → bath → cinema → study → infinity edge →
  fire terrace → coast. Sixteen cinematic keyframes are interpolated with a
  virtual dolly (per-scene scale and drift plus long crossfades), so every
  pixel of scroll renders a unique frame — the image-sequence effect without
  shipping hundreds of files.
- **Fifteen content acts** — story, live statistics, featured projects with
  expanding previews, a pinned horizontal room showcase with fullscreen
  viewing and a floor plan, pillars, services with hover previews,
  investment metrics over a parallax skyline, timeline, awards,
  testimonials, FAQ, contact with floating-label form, and a luxury footer.
- **Interaction layer** — Lenis smooth scrolling on GSAP's ticker, magnetic
  buttons, a champagne cursor with contextual labels, masked text reveals,
  animated counters, film grain, and glass morphism throughout.

## Art direction

A light "golden morning" grade: warm white stone, cool glass, sage greenery,
bronze linework, and soft sun haze. Every image on the site is generated by
an in-repo procedural pipeline (`scripts/`): scenes are composed as layered
SVG and rasterised to optimised WebP with tiny blur placeholders (25 assets,
under 1 MB total). Deterministic seeds make builds reproducible:

```bash
npm run generate:assets
```

## Stack

Next.js 15 (App Router, static output) · React 19 · TypeScript · Tailwind CSS
· GSAP + ScrollTrigger · Lenis · Framer Motion · Lucide · sharp (build-time
asset pipeline).

## Performance & quality

- All imagery is preoptimised WebP with blur placeholders; the walkthrough
  preloads progressively and renders on a DPR-capped canvas.
- Below-the-fold sections are code-split via dynamic imports.
- Fully static prerender; ~216 kB first-load JS.
- Semantic landmarks, labelled controls, keyboard-closable dialogs, and a
  `prefers-reduced-motion` experience (animations collapse; the walkthrough
  becomes an editorial sequence of stills).
- SEO: metadata, Open Graph, JSON-LD (`RealEstateAgent`), robots, sitemap.
